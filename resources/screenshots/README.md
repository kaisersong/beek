# Welcome-page images

The Chinese and English PNGs show the native macOS onboarding welcome page from BeeK 1.1.1 (`8e45122c7b0b1fb3e091697233bbaa94bd95529e`). The app content view was exported in an isolated documentation build; no desktop, account credentials, or user-selected text is included. The displayed translation is the built-in public example. No UI controls were redrawn or composited for these images.

These assets are used by the repository READMEs. They do not change the shipped app or its runtime resources.
