## 再次攻击的边界

- 剪贴板延迟渲染可卡住 GetClipboardData：§6.1 把只读操作放入可终止 helper，UI/输入线程不做读取；未知来源路径只显式预览，不能翻译错误归属的“当前选区”。
- Credential Manager 与旧 translate.rs 的明文字段不匹配：§8 增加 CredentialResolver 和单请求冻结配置快照，不会因为凭据迁移后 api_key 为空而绕过已保存凭据。
- 所有平台入口和 GPUI 窗口契约仍可能在实现时被证伪：G0 明确阻塞 G1–G5，不能靠本评审 PASS 越过实测。
