## 已实现

- 平台入口拆分：原 macOS main 移至 `src/macos_main.rs`，内容保持基线字节一致；Windows 专有依赖隔离，保留 root Cargo.lock 和精确 GPUI0.2.2。
- UIA 仅在可终止 helper 中执行；原子 Job 归属、协议/来源/nonce/创建时间校验、1500ms 总预算、2个UIA与1个剪贴板进程上限、6次/10秒创建预算、来源退避和隔离。
- 非激活蜜蜂与实时翻译卡；普通快照需确认后联网；字段支持 UTF-16/IME 与有界异步剪贴板；HTTP 为2个真实工作线程加1个最新等待项，SSE/正文/时间有界。
- Windows Credential Manager 不可变引用与原子配置事务；跨进程保存锁、旧明文迁移、损坏备份、失败回滚和迟延孤儿清理。Known Folders 路径不依赖 cwd。
- 当前用户/会话单实例与受限管道、两阶段手动重启交接、托盘重建、热键、默认关闭自启动和复制监控、固定语音工作线程、固定 HTTPS 手动更新入口。
- 用户级 Inno 安装器、不可变版本目录和安装锁、默认卸载保留数据；主程序/helper 同构建验证，静态 CRT，内部/正式签名模式隔离。
- 87项机器可读用例、真实协调器/网络故障 harness、受限桌面驱动、能力/源码/资产证据校验、第三方声明生成与双平台发布聚合工作流。
